## Instrução

Publique um manual de usuário final chamado **"Configurar endereço do restaurante"**, na seção
**Cardápio Digital**. Use o conteúdo de `manuais/endereco-restaurante/endereco-restaurante.md`
como fonte, **sem reescrever o texto**.

Este manual é **pré-requisito** dos quatro de área de entrega (#35 mapa, #36 KM, #37 bairro,
#38 CEP Fixo). Publique este primeiro.

### Estrutura a preservar

1. Duas coisas para saber antes (endereço da loja ≠ do cliente; só um tipo ativo)
2. Onde fica
3. Parte 1 — Confirmar a localização (inclui a digitação do endereço)
4. Parte 2 — O número é obrigatório
5. Parte 3 — Escolher o tipo de entrega
6. O que o cliente vê
7. Resumo do caminho
8. Perguntas frequentes
9. Manuais relacionados

### Pontos que NÃO podem se perder

- Sem o pin da loja, KM e mapa calculam a partir do lugar errado.
- Digite **Rua Caramuru, 108, Vila Leão, Sorocaba** — é o endereço da loja.
- O **número é obrigatório** no modal Confirmar Endereço (108).
- Só um tipo de entrega fica ativo; trocar não apaga os outros cadastros.
- A mudança leva **1 a 2 minutos** para chegar ao cardápio digital.
- Teste no cardápio: **R. Arthur Gomes, 13 — Centro, 18035-490** (não é o endereço da loja).
- Os quatro tipos apontam para os manuais #35–#38.
