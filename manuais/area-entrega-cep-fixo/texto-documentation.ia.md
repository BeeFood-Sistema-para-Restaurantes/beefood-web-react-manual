# Prompt para publicar o manual — Configuração por CEP Fixo (#38)

Publique **"Configuração por CEP Fixo"** na seção **Cardápio Digital**, usando
`manuais/area-entrega-cep-fixo/area-entrega-cep-fixo.md` **sem reescrever**. Depende do #34.

### Pontos que NÃO podem se perder

- Só para cidade com **um CEP**. Cidade grande usa bairro ou KM.
- Não é frete único para qualquer CEP: o CEP do cliente tem que ser **igual**.
- **Salvar (F2)** é obrigatório — esta tela não grava sozinha.
- **1 a 2 minutos** para o cardápio; o cliente deve **Trocar** o endereço.
